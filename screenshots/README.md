# Screenshots

This folder holds the visual evidence for the lab. Expected files:

| File | What it shows |
|---|---|
| `01-aduc-ou-structure.png` | Active Directory Users and Computers — the `IT_Sektor`, `Prodaja` and `Uprava` OUs and the users inside them |
| `02-dhcp-scope-authorized.png` | DHCP console — `Lan_Scope` (`192.168.31.100–200`) with the green authorised check mark |
| `03-mapped-p-drive.png` | Windows 10 desktop — the `P:` drive mapped by Group Policy |

Guidelines:

- Use PNG, keep each file under ~1 MB.
- Blur or crop out licence keys, product IDs, personal e-mail addresses and
  anything that is not part of the lab.
- Use lowercase, dash-separated file names.

The main `README.md` already references these three paths, so once the files
are dropped in here they render automatically.
